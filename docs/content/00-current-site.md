## 9. 棚卸しで見えたこと

### すぐ直すべき不具合
- **お問い合わせフォームが何も送っていない。** `contact-form.tsx` の送信処理は画面を「送信完了」に切り替えるだけで、メールも保存もしていない。これまでの問い合わせは全部消えている可能性がある。
- **プライバシーポリシーのページが存在しない。** フォームに「同意したものとします」とあるのにリンク先が無い。

### 中身が薄い理由（書き直しで埋めるところ）
1. **具体的な数字や事例が一つも無い。** 「安価に」「豊富な計算資源」「業界水準より大幅に」と言うだけで、いくらなのか、何と比べてなのかが書かれていない。導入事例・実績・取引社数も無い。
2. **同じ文の使い回し。** 「保守から運用まで完全自社完結。豊富な計算資源を安価に」がトップ・事業内容・記事・提供形態で4回出てくる。「代表が選ぶ現場の精鋭に…最新AI」も3回。
3. **実際の稼ぎ頭が載っていない。** MEO / SEO の集客支援は代表プロフィールの1文にしか出てこない。事業内容にも keywords にも無い。
4. **誰向けかが書かれていない。** 大企業の情シス向けなのか、地元の中小・個人店向けなのか、ページから読み取れない。
5. **「どう頼むか」が無い。** 料金の目安、契約の流れ、期間、最低契約単位、対応地域が無い。
6. **会社の実在感が弱い。** 設立年・資本金・人数・電話番号・沿革・写真（ストック写真のみ）が無い。メンバーも代表1人で経歴が無い。
7. **裏付けの無い言い切り。** 「24/365 の監視体制」「物理層からの完全マネージド」「エンジニア育成プログラム」などは、実際の体制と合っているか確認が要る。派遣を名乗るなら許可番号の記載が要る。
8. **ナビの名前が紛らわしい。** 「事業内容」と「サービス」が並び、後者はお知らせ欄。

### 残せそうなもの
- 社名とスローガンの由来（相関の線から外れた点＝OUTLIER）。散布図の絵はこの話と組み合わせれば効く。
- kuki-dc を代表が自分で設計・運用しているという事実。他社がまず持っていない具体的な強み。
- CORE STACK の具体名（Kubernetes, Argo CD, Cilium など）は、技術者向けには中身として機能している。
