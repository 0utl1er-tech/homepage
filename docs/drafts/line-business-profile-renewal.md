# LINE公式アカウントの「ビジネスプロフィール」が10月28日に変わります。お店がいまのうちに確認しておく5つのこと

LINE公式アカウントのプロフィールページ（ビジネスプロフィール）が、2026年10月28日（水）から順にリニューアルされます。LINEヤフーが発表しました。

見た目が少し変わるだけ、ではありません。**今の設定によっては、書いておいた情報が消えたり、電話番号が勝手に入れ替わったりします。** 店舗でLINE公式アカウントを使っている方は、28日までに一度プロフィールを開いて確認しておくことをおすすめします。

この記事では、変更点のうちお店に関係する部分と、事前にやっておくことをまとめます。あわせて、Googleマップ（Googleビジネスプロフィール）やホームページと情報をそろえる方法も紹介します。

## 何が変わるのか（要点）

1. **お店の基本情報を1か所で管理する画面ができる**
   電話番号・住所・支払い方法などが、新しい「プロフィール情報設定画面」にまとめられます。公開すると、変更がLINEの各サービスにすぐ反映されます。
2. **「保存しただけで非公開」の情報は消える**
   リニューアルの時点で公開している情報は引き継がれますが、保存だけして非公開にしている情報は削除されます。
3. **「通話」ボタンの電話番号が統一される**
   「通話」ボタンの番号と「電話番号」の設定に別の番号を入れている場合、プロフィール情報設定画面の番号にそろえられます。
4. **パーツの「一時的に非表示」ができなくなる**
   パーツの状態は「下書き保存」と「公開中」の2つだけになります。公開中のパーツを隠したいときは「削除」になり、「自由記述」「お知らせ」「アイテムリスト」「よくある質問」は削除すると元に戻せません。
5. **いくつかのパーツが廃止・縮小される**
   たとえば「お知らせ」は登録できる件数が200件から20件になり、最新の20件以外は削除されます。「最近の投稿」パーツは廃止され、投稿していた画像・動画も削除されます。基本情報の「紹介文」は廃止され、新しい形には移行されません。

## 28日までに確認しておく5つのこと

### 1. 「紹介文」を控えておく

今の紹介文は新しい形に移行されません。お店の説明として大事な文章を書いている場合は、どこかにコピーしておき、リニューアル後に「ステータスメッセージ」などで書き直せるようにしておきましょう。

### 2. 非公開で保存している情報がないか

電話番号・住所・営業時間・支払い方法などを「保存だけして公開していない」状態にしていると、その情報は削除されます。載せたい情報は公開にしておく、不要なら消えても困らないか確かめておく、のどちらかです。

### 3. 「通話」ボタンの番号と、表示している電話番号が同じか

予約用と代表番号を分けているお店は要注意です。リニューアル後は1つの番号にそろうので、どちらの番号でお客様からの電話を受けたいかを決めておきましょう。

### 4. 「お知らせ」が20件を超えていないか

古いお知らせは最新20件を残して削除されます。残しておきたい告知（料金表やよくある案内など）がお知らせに埋もれている場合は、別の場所に控えるか、「よくある質問」など別のパーツに移しておきます。

### 5. 一時的に隠しているパーツをどうするか

季節メニューなどを「非公開」にして取っておく使い方は、リニューアル後はできません。今後は削除になるので、使い回したい内容は文章や画像を手元に保存しておくと安心です。

## ついでにやっておきたい「情報をそろえる」作業

今回の変更で、LINEのプロフィールは「基本情報を1か所で管理する」形になります。これはお店にとって、情報を見直すよい機会です。

お店の情報は、LINEのほかにもいろいろな場所に載っています。

- Googleマップ（Googleビジネスプロフィール）
- お店のホームページ
- Instagramなどのプロフィール
- 予約サイト・グルメサイト

このうちどれか1つでも営業時間や電話番号が古いままだと、お客様が迷ったり、閉まっている時間に来店してしまったりします。Googleも、Googleビジネスプロフィールの情報は正確で最新の状態に保つよう案内しています。

### そろえるときの手順

1. **正しい情報を1つの表にまとめる**
   店名、住所（表記も含めて）、電話番号、営業時間、定休日、臨時休業の予定、支払い方法、予約方法、ホームページのURL。
2. **住所と店名の書き方を統一する**
   「3丁目2-11」と「3-2-11」、「株式会社」の有無など、表記ゆれを1つに決めます。
3. **表を見ながら、各サービスを順に直す**
   LINE（新しいプロフィール情報設定画面）、Googleビジネスプロフィール、ホームページ、SNS、予約サイトの順など、決まった順番で回ると漏れが減ります。
4. **臨時休業や年末年始は「全部に入れる」を習慣にする**
   1か所だけ更新して他を忘れるのが、いちばん起きやすい失敗です。

## まとめ

- LINE公式アカウントのビジネスプロフィールは、2026年10月28日から順にリニューアルされます。
- 非公開で保存している情報や紹介文、古いお知らせ、「最近の投稿」の画像・動画は消える可能性があります。28日より前に一度プロフィールを開いて確認しましょう。
- 電話番号は1つにそろうので、どの番号で電話を受けるかを決めておきましょう。
- あわせて、Googleマップやホームページの情報もそろえておくと、お客様が迷わなくなります。
